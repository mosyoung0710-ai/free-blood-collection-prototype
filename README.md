# 免费高危筛查交互原型

这是免费高危筛查需求的交互评审原型，覆盖筛查方式选择、免费采血申请、线下核销、报告上传及未来地区筛选示例。

## 查看原型

发布完成后，点击 [GitHub Pages 演示页](https://mosyoung0710-ai.github.io/free-blood-collection-prototype/) 查看。

## 说明

- 原型仅用于流程和页面交互评审，不连接真实业务系统。
- 页面中的人员、服务点和申请信息均为演示数据。
- 不包含真实患者信息、医疗机构名称、联系方式或接口信息。

## 本次重点

- 免费与收费筛查方式分流。
- 免费采血申请记录的状态入口与报告上传回流。
- 未来新增地区时的地区筛选无服务状态。
